0. Tujuan, Baseline, dan Batas STEP
STEP 05 mengubah hasil STEP 03-04 menjadi blueprint implementasi UI yang stabil. Tujuannya bukan menambah ide visual, melainkan membekukan hierarchy, layout, behavior, copy, state, dan reference supaya implementer berikutnya tidak melakukan redesign diam-diam.
Membekukan AAVC 1:1 sebagai visual/workflow authority untuk ANG.
Membekukan hubungan Screen ID <-> UI reference <-> state <-> interaction <-> control semantics.
Membedakan bagian immutable, resizable/adaptive, dan provisional teknis.
Mengunci kebijakan manual UI dan AI Agent agar menuju semantic command layer yang sama.
Menentukan change-control pasca-freeze dan future implementation-conformance gate.
Tidak memilih framework/engine/detail architecture — itu milik SF-STEP 06.
Tidak menulis source code, tidak fork/copy upstream, tidak membuat build.

10. Control-Level Behavior Contract
	Control / Intent
	Semantics

	Simpan
	Persist current project state; status reflects success/failure, never fake green.

	Undo/Redo
	Moves shared history pointer; manual and AI transactions participate.

	Import/Relink
	Never changes stable Axxx identity silently; validation rechecks affected links.

	Lock
	Random/AI must respect lock unless explicit unlock/override confirmation.

	Preview
	Shows current project state; stale preview must be indicated or rebuilt.

	Split/Trim/Resize/Move
	Creates deterministic timeline command + history entry.

	AI Terapkan
	Applies only validated non-stale plan as transaction.

	AI Batal
	No domain mutation.

	Validasi Ulang
	Reruns validation and refreshes issue list; does not auto-delete user data.

	Render
	Requires validation of blocking issues and captures deterministic render plan.

	Batalkan Render
	Stops job safely; temporary output cannot be labelled final.

	Recovery Pulihkan
	Loads recovery state without silently destroying original file.

	API Test
	Tests masked credential slot; never exposes secret after import.



11. Frozen Timeline Interaction Blueprint
Canonical selection synchronizes timeline, preview, scene/asset list, and inspector.
Drag/reorder/move, trim/resize, split, In/Out, markers, magnetic snap, zoom, follow-playhead, navigator/scroll, play-selection, context menu, and lock are user-facing contracts.
Magnetic snap must have visible feedback; follow-playhead must not fight intentional manual scrolling.
Long-project timeline must remain operable with many scenes; exact virtualization/threading belongs to STEP 06.
Every mutating action maps to semantic command/history entry; direct widget mutation is not authoritative domain state.
12. Frozen AI Agent / AI Director UX Blueprint
	State
	Required UX

	READY
	Scope visible; natural-language input; examples/suggestions optional; manual editor remains editable.

	PLAN
	Concrete edits listed by scene/asset/control semantics; impact visible; stale plan detectable.

	APPROVAL
	Material change waits approval where required; cancel mutates nothing.

	APPLYING
	Busy state; prevent duplicate apply; transaction tracked.

	SUCCESS
	Summary + Undo/Lihat Timeline; no exaggerated capability claim.

	PROVIDER_ERROR
	Distinguish no key, invalid, rate-limit, network/provider; provide manual fallback.

	LOCK_CONFLICT
	Explain locked target; do not silently override.

	STALE
	Reject or rebuild plan when project state changed.



AI must not mutate arbitrary ProjectState/JSON. It produces Edit Plan -> validator -> typed command(s) -> transaction/history. UI and AI therefore share domain semantics rather than two separate editing systems.
13. Frozen Subtitle Blueprint
Cue list + editable text + start/out timing + split/merge/reload SRT.
Style: typography, color, outline, shadow/background box, alignment/safe-area.
Animation presets only when backed by real runtime effect.
Per-word timing editor and karaoke/highlight variants represented by UI-035/036.
Preview must show relevant cue/state; final render parity validated later.
Source text must not be silently rewritten by style/timing operations.

15. Frozen Validation, Relink & Recovery Blueprint
Blocking input/missing media issues identify exact Scene/Asset ID and actionable fix.
Validation Center groups errors/warnings by scope; severity not color-only.
Relink changes file binding while preserving canonical identity unless user explicitly remaps identity.
Recovery shows autosave age/path/source and never silently overwrites sole usable original.
Scan/import progress shows current progress/file and cancel behavior if supported.
Diagnostics/log views redact credentials and do not replace human-readable primary message.

	Contract

	ADVANCED

17. State Language, Copy, Accessibility & Feedback
	State
	Meaning

	EMPTY
	No content yet; explain next useful action.

	READY
	Usable and current.

	DIRTY
	Unsaved changes.

	BUSY
	Operation in progress; duplicate action guarded.

	PARTIAL
	Some inputs/results available.

	WARNING
	Non-blocking problem.

	BLOCKED
	Cannot continue until required issue fixed.

	ERROR
	Operation failed; state preserved where possible.

	SUCCESS
	Operation verified complete.

	OFFLINE_NO_PROVIDER
	Manual path remains.

	STALE
	Preview/plan/result older than project state.

	RECOVERY
	Recovery decision required.

	LOCKED
	Protected from random/AI/manual action as defined.

	SELECTED
	Current target across coordinated surfaces.

	VALIDATING
	Validation running.



Active/selected state uses shape/border/icon/text as well as color.
Primary action remains visually distinguishable but destructive actions are not styled as primary positive action.
Error message says what happened + where + next action, not only “gagal”.
Generated sample typo/text is not frozen if it conflicts with canonical runtime copy; geometry/hierarchy remain frozen.
Keyboard focus, tab order, text scaling/DPI behavior must be considered in implementation without redesigning layout.
18. Immutable vs Adaptive vs Provisional
	Class
	Items
	Rule

	IMMUTABLE
	Shell hierarchy, main panel ownership, white/blue design language, primary workflows, Screen/UI IDs, command semantics, AI approval/fallback, key masking.
	Change only by owner-approved change record or hard technical/legal blocker.

	ADAPTIVE
	Panel resizing within bounds, scrollbar/overflow, DPI scaling, text wrapping, long-list virtualization, exact pixel allocation below canonical viewport.
	May adapt without changing hierarchy or meaning.

	PROVISIONAL_TECH
	Exact Qt/PySide/libopenshot/MLT integration, native player bridge, project schema format, threading, packaging, effect implementation mapping.
	Decide SF-STEP 06; cannot invalidate frozen UX silently.
