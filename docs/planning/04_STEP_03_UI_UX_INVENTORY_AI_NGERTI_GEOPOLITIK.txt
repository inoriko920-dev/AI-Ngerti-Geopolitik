12. Special Desktop / File / Media Flows
File/folder paths with spaces and Unicode must remain readable. A stale path is surfaced; never silently redirected.
Missing/corrupt/duplicate media appears as explicit asset status and validation issue. Relink preserves canonical Axxx identity.
Long DOCX parse/asset scan/media probe must show WORKING/progress and allow cancel when implementation supports safe cancellation.
Output collision must not overwrite existing user output silently; behavior is confirmed later in architecture/export implementation.
Low/full disk or unwritable output becomes actionable render/persistence error; existing project/source remains intact.
Portable folder move must not depend on hard-coded C:/D: developer paths.
Bundled/external media dependency unavailable must show readiness error; normal user is not instructed to install developer runtime.
Large projects (20/100/300 scenes) require scrolling/selection/timeline virtualization behavior that remains understandable; exact performance targets are benchmarked later.
13. AI / API / Credential UX Contract
AI panel shows scope before request (project/scene/asset where relevant).
Gemini request runs as background job; editor remains responsive.
AI response becomes structured Edit Plan. Unknown command/target/value, user lock conflict, unsupported render primitive, or stale project revision must reject before mutation.
Apply is one clear history transaction or documented grouped intent; Undo must be visible/available.
No-key, invalid credential, 401/403, 429/quota, network, provider 5xx, and malformed response are distinguishable user-visible failures.
Credential UI supports slots 1–100, but normal saved-state UI shows slot/status only, never raw key.
AI must not change credential/output folder/project path as part of Auto Edit.
Manual editing remains available when AI is unavailable.
14. Persistence / Recovery UX
Dirty indicator appears in window title/project state after unsaved mutation.
New/Open/Close/Exit while dirty invokes Save / Discard / Cancel. Save failure cancels destructive continuation.
Recovery snapshot is separate from source project and presented as recoverable candidate; source is never overwritten silently.
Relink changes and AI/manual edits enter history before persistent save.
Subtitle cue save-copy must not silently overwrite source SRT when the flow is defined as copy.
Project reopen must restore scene order, timing, binding, subtitle/narration, locks, and relevant settings.
Legacy migration (if enabled) is read-only against legacy source and produces compatibility report.
