9. AI AGENT UX CONTRACT
- manual editing remains functional when AI/network/key fails;
- context/scope is visible before material edits;
- executable changes are summarized before commit where approval is required;
- invalid/stale plan is rejected or repaired;
- apply is transaction/undoable;
- locks are respected;
- no-key/invalid/rate-limit/network/provider errors remain distinguishable;
- saved UI/logs never redisplay raw API keys;
- up to 100 credential slots do not imply quota multiplication;
- AI may only offer operations backed by actual command handlers.

10. VALIDATION / RECOVERY / FILE UX
- required missing/unreadable inputs block only the relevant operation and show an actionable reason;
- missing assets are identified by canonical Axxx and can be relinked;
- portable paths cannot assume C:/ or D:/;
- recovery never silently overwrites the only usable project state;
- render failure preserves project and deterministic/random/AI decisions;
- unsaved close/open uses explicit guard behavior;
- diagnostics redact credentials.
