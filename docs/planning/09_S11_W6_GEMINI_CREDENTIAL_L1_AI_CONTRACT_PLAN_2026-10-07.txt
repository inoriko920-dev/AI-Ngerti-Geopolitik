5. CREDENTIAL SECURITY CONTRACT
- Credential bukan ProjectState.
- Logical slot 1..100.
- Production secure store: Windows Generic Credential / keyring WinVault-compatible.
- Metadata non-secret: slot_id, label, enabled, health, last result category, bounded cooldown.
- Raw key hanya secure store; presentation tidak menerima raw saved key.
- Provider/credential service boleh mengambil raw key hanya saat request/test.
- Tidak ada raw key di repo/.angproj/settings/evidence/screenshots/logs/exceptions/CLI args/URL/prompt.
- Delete menghapus secret + metadata.
- Slot 0/>100 ditolak.
- Bulk TXT hanya setelah single-slot stabil: one key/line, trim, dedupe, max100, source tidak disimpan, count-only preview, no plaintext logging.
- Failover hanya operational resilience legal, bukan quota circumvention.

6. ERROR TAXONOMY

Provider failure tidak memblok manual editor. Invalid/stale/error = zero canonical mutation.

7. EDITPLAN CONTRACT
DTO application-layer, bukan ProjectState.
Minimal fields: schema_version, base_project_revision, request_id/job_id, summary, ordered command proposals.
PlanVerifier: strict schema → allowed command → target existence → lock → supported capability → ranges → stale revision → dry-run → approval.
Unknown field/command/target/effect atau out-of-range = reject.
Stale checked ulang immediately before apply.
One approved plan = one CommandBatch / one Undo transaction.
Cancel = zero mutation.

8. CONTEXTBUILDER
Allowed bounded context: project/global style summary, scope/target IDs, media aspect/type, current effect/intensity/lock, bounded neighbor summary, supported enum/ranges, current revision.
Forbidden: API key, credential secrets, arbitrary filesystem, unrestricted files, engine objects, private logs, source media bytes.
Project/prompt text adalah untrusted data.
