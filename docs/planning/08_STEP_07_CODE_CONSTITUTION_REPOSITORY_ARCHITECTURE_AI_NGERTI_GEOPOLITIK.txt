COMMAND / HISTORY
UI/menu/shortcut/context/AI all dispatch semantic commands.
Command contains stable IDs, typed payload, actor, command_id, expected_revision.
Handler validates existence/range/locks/capabilities/revision.
Command/CommandBatch commits atomically.
One approved AI request = one grouped HistoryEntry.
Engine sync happens after domain commit. Engine failure is recoverable and never becomes product truth.
Retried external completions use task/operation IDs to avoid double apply.

PRESENTATION
AAVC 42/42 frozen references are visual/interaction target.
QMainWindow owns layout orchestration only.
Centralized design tokens/QSS.
Important controls use stable objectName.
Widgets emit intent; viewmodels/application execute use cases.
Long work never blocks GUI thread.
No static PNG runtime UI.

MEDIA / PROCESS
Only infrastructure/media adapter imports libopenshot or MLT.
Vendor types never leak to application/presentation.
Both real adapters must satisfy same MediaEnginePort contract tests.
Do not maintain two parallel production engines.
FFmpeg/ffprobe execution only via dedicated boundary/ProcessRunner; shell=False; validated argument arrays.
Native/plugin/codec capability exposed through CapabilityRegistry.
Bundled native payload requires provenance/license/checksum manifest.

AI / GEMINI
google-genai import only inside infrastructure/ai/gemini.
AIProviderPort returns ANG-owned types.
Minimum context; no raw secret in prompt.
Tool registry exposes semantic edit operations, not arbitrary shell/filesystem.
PlanVerifier checks schema/IDs/revision/locks/range/capability.
Approved plan -> CommandBatch -> same CommandBus.
Credential rotation follows provider policy and must not be designed/documented as quota circumvention.

JOBS / CONCURRENCY
UI thread is presentation only.
JobManager owns job lifecycle/cancel/progress/stale.
Workers never mutate QWidget/ProjectState directly.
Result applies only after session/project revision/task ID validation.
Render child process by default.
Preview uses serialized EngineSession; process isolation remains qualification-driven.
Concurrency bounded.

PERSISTENCE / PATH / SECRET
Native .angproj versioned JSON.
Atomic save: validate -> temp -> flush/close -> replace.
Autosave/recovery separate; migration versioned/tested/backup-aware.
Relink changes path/reference, never Axxx identity.
PathService resolves app/resources/user/cache/log/recovery; no developer C:/D:.
Resources read-only at runtime.
Raw API key only CredentialPort; never project/settings/log/tests/screenshots.
Structured redacted logging and typed error taxonomy.

DEPENDENCY POLICY
